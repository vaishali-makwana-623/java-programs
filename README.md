Java Programs

This repository contains basic Java programs created for learning and practicing Java programming concepts.

📚 Programs
HelloWorld.java – Basic Hello World program
Calculator.java – Performs basic arithmetic operations
EvenOdd.java – Checks whether a number is even or odd
Factorial.java – Calculates the factorial of a number
PrimeNumber.java – Checks whether a number is prime
Student.java – Basic Student class program
StudentConstructor.java – Demonstrates constructors in Java
StudentGrade.java – Calculates student grade
Inheritance.java – Demonstrates inheritance
MethodOverloading.java – Demonstrates method overloading
Palindrome.java – Checks whether a number is a palindrome
Armstrong.java – Checks whether a number is an Armstrong number
Fibonacci.java – Generates Fibonacci series
ReverseNumber.java – Reverses a number
CountDigits.java – Counts the digits of a number
SumOfDigits.java – Calculates the sum of digits
SwapNumbers.java – Swaps two numbers
LargestNumber.java – Finds the largest among three numbers
🛠️ Technologies Used
Java
Object-Oriented Programming
Basic Java Concepts
🎯 Purpose

This repository is created to practice Java programming concepts and maintain a collection of simple Java programs.
